## Overview

NARO presents wallet participation, rewards, community information, and network data in a dark interface with green-tinted surfaces and mint actions. This is a reconstructed draft of the existing public interface.

## Colors

Use the mint action color with the dark action foreground. Keep supporting prose in the secondary text color, distinct from primary balances and headings.

## Typography

Use the sans family for body copy and controls. Preserve the numeric family for numeric displays and the activation code treatment.

## Layout

The existing Home, Mining, and Activate pages share a narrow content shell and bottom navigation. Treat that shell as observed layout behavior when comparing the revamp with the current product.

## Shapes

Keep the existing distinction between rounded cards, primary action buttons, and pill-shaped header controls when reconstructing the deployed interface.

## Components

Primary actions pair a mint background with dark text. Header connection controls use the pill shape; page-level primary actions use the button shape.
